# 《我们都认识他》网页端 / PWA

本目录是从微信小程序原型迁移得到的独立网页版本。当前已接入无剧透背景简报、Q01—Q12完整流程、全部分支反馈与E1—E6六个结局。

## 已迁移内容

- 剧情状态机、10项状态变量、证据册、选择记录和E1—E6结局优先级。
- 94个可达节点、12道选择题、6144条合法路线和6个结局。
- 玩家视角改写的剧情文本、35张图片、6段无声运镜视频。
- 后半程专用画面与网页推近、横移、淡入轻量动画。
- 浏览器本地存档、继续游戏、重新开始、证据抽屉、状态抽屉。
- 支持完整状态单步撤回；每次只能退回一个界面，不能连续撤回。
- 恋爱借款聊天以原生气泡展示，玩家可直接比较句号、短句、空格和波浪号习惯。
- v0.5 新增六张专用剧情画面，全部94个节点均保留对应视觉或聊天界面。
- v0.6 增加逐幕调查路标、具体行动按钮与两张玩家视角连接画面，交代每次转场的原因、去向和目标。
- 手机竖屏与桌面双栏响应式 UI。
- PWA 清单、Service Worker 与离线缓存基础。
- 音频独立清单；没有配音时自动使用文字，不阻断游戏。

## 本地运行

不要直接双击 `index.html`，ES Module 和 Service Worker 需要 HTTP 服务。

```powershell
cd "E:\26秋\反诈设计大赛\projects\we-know-him-web"
python -m http.server 4173
```

浏览器访问 `http://localhost:4173/`。停止服务器按 `Ctrl+C`。

## 目录

- `src/core/`：平台无关状态机与浏览器存档。
- `src/data/`：剧情、画面和音频清单。
- `assets/`：图片、视频、未来配音。
- `tests/`：剧情路由与结局规则验证。
- `docs/WEB_ROUTE_GUIDE.md`：网页端完整制作和发布步骤。

所有机构、凭证和金额画面均为虚构游戏道具。

## 试玩设备

- 手机、平板、Windows 或 macOS 电脑均可，无需安装客户端。
- 建议使用近两年版本的 Chrome、Edge、Safari 或 Firefox。
- 首次打开需要联网加载约数 MB 的图片与短视频；完成加载后支持基础离线缓存。
- 手机建议竖屏，屏幕宽度 360px 以上；电脑端建议 1280×720 以上。
- 游戏进度保存在当前浏览器本地。无痕模式、清理网站数据或更换设备会丢失进度。
