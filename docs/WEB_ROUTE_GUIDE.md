# 线路 2：网页端 / PWA 完整实施步骤

## 一、路线目标

交付一个可通过网址或二维码进入、手机与电脑均可游玩、支持本地存档并能在浏览器中安装的互动推理游戏。网页作为唯一主版本；以后需要 Windows 展示版时，可直接用 Tauri 封装该网页项目。

## 二、已经完成的迁移

1. 建立无框架、无打包依赖的 ES Module 项目。
2. 将小程序状态机改为浏览器可导入模块，保持所有节点 ID 和状态名不变。
3. 将微信存储接口改为 `localStorage`。
4. 将 WXML/WXSS 页面重写为 HTML/CSS/JavaScript。
5. 迁移 20 张图片与 6 段 MP4，并把资源路径改为网页相对路径。
6. 迁移音频空插槽，保证配音可独立补充。
7. 增加手机单列、桌面双栏、自适应安全区与键盘操作。
8. 增加 PWA manifest、Service Worker 和离线缓存基础。
9. 迁移 Q01/Q02 四条路径测试及 E1—E6 结局优先级测试。

## 三、完整开发步骤

### 阶段 A：把终稿全部数据化

1. 冻结 `Q01—Q12`、`E1—E6`、证据 ID 和角色 ID。
2. 从终稿逐幕录入 Q03—Q12：场景节点、选择节点、分支反馈、下一节点。
3. 为每个选择只在 `effects` 中写状态和证据，正文不暗改状态。
4. 接入六个结局节点，并在 Q12 后调用结局判定。
5. 添加可达性检查：不存在断链、死循环、无入口节点和失效媒体。
6. 自动遍历全部 6144 条合法选择组合，核对每条路线必达一个结局。

验收：纯文字和占位图条件下，可以从开场玩到任一结局。

### 阶段 B：完成网页专项 UI

1. 制作角色关系板，可按时间点逐步解锁关系。
2. 制作证言对照界面，明确“谁在何时看见了什么”。
3. 为 Q04、Q05、Q07、Q09、Q12 开发专项交互，而非全部使用普通按钮。
4. 增加章节目录、结局回看、证据回看和已读快进。
5. 增加字幕字号、动态效果和声音开关。
6. 用 360×800、390×844、768×1024、1366×768、1920×1080 五组尺寸检查。

验收：手机可单手操作，电脑投屏信息不稀疏，选项不会被底栏遮挡。

### 阶段 C：补齐画面和视频

1. 以 104 镜清单为索引，为每个镜头分配稳定媒体键。
2. 优先完成 Q03 座谈、Q04 真文件、Q05 双文风、Q07 隐形人、Q09 AI 冒名视频和 Q12 终幕。
3. 人物对白不烘焙进画面；图片/视频只保留人物、场景与镜头运动。
4. 网页首屏图片输出 WebP；视频输出 H.264 MP4，另备 WebM 可选版本。
5. 非当前章节媒体延迟加载；长视频放对象存储/CDN。

验收：弱网时先显示封面，视频失败不会阻断剧情和选择。

### 阶段 D：自然配音与声音

1. 每个主要角色先做 2 段盲听样音，确定音色、语速和情绪范围。
2. 每句台词生成独立文件，文件名使用节点 ID，例如 `a01.mp3`。
3. 在 `audio-manifest.js` 填写 `src` 和实际 `durationMs`。未填写时，游戏按角色音色表调用设备上的中文自然语音。
4. 分离旁白、人物对白、环境声和提示音；提供统一音量标准。
5. 浏览器首次播放必须由用户点击触发，之后才允许自动续播。

验收：同一角色全程音色一致，手机外放能听清，关闭声音后完整可玩。

### 阶段 E：质量检查

1. 自动跑剧情结构、全部路线、结局优先级和媒体缺失检查。
2. 用 Chrome、Edge、Firefox 与至少一台 iPhone/Android 真机测试。
3. 测试刷新恢复、跨章节存档、断网重开、视频加载失败和浏览器返回键。
4. 检查虚构标识、隐私说明、作品介绍和 100 字内创作说明。
5. 录制一条 2—3 分钟完整演示视频，作为评审打不开网页时的备份。

### 阶段 F：部署与提交

1. 选择支持 HTTPS 的静态托管平台或校内服务器。
2. 上传本目录全部文件，保持相对目录不变。
3. 配置自定义域名或稳定二级域名。
4. 部署后检查 Service Worker、视频跨域、缓存更新和手机全屏安装。
5. 生成二维码，并准备“线上网址 + 本地离线包 + 演示视频”三份交付。

## 四、版本管理规则

- 网页端是主版本，后续不再手工同步小程序 WXML。
- 剧情文字只改 `src/data/story.js`。
- 画面只改 `media-manifest.js` 与 `assets/`。
- 配音与音乐只改 `audio-manifest.js` 与 `assets/audio/`。对白播放时，背景音乐会自动降低音量。
- 每次更新 Service Worker 缓存内容时递增缓存版本号。
- 发布前保留一个可回退压缩包，文件名包含日期和版本号。
