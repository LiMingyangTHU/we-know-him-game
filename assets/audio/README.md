# Audio design

The four MP3 files are original procedural underscore generated by
`scripts/generate_bgm.py`.

- `bgm-inquiry.mp3`: opening, interviews and evidence review
- `bgm-pressure.mp3`: AI identity, hidden runner and money pressure
- `bgm-truth.mp3`: verification, confrontation and publication decisions
- `bgm-aftermath.mp3`: endings and reflection

Character speech only plays reviewed static files listed in
`src/data/generated-voice-takes.js`. There is no device text-to-speech fallback.
Act 1 takes use separate voices for Lin Zhixia, Liang Yizhou and Zhou Heng, with
sentence-level timing and consistent loudness. Generation details and measured
durations are stored in `act1-voice-report.json`.
